03 / OPEN EVERY BIN

Signed gaps can cancel

Each occupied bin contributes |sum(confidence) - sum(correct)| / N to ECE. MCE is the largest absolute within-bin mean gap. Neither is the mean of per-row absolute error. Binning and small counts change these estimates.

Original before/after reliability tables
The caller example is deliberately adverse: validation picks the upper boundary T=10, but test NLL worsens. Uniform ties, within-bin cancellation and a wrong singleton with underflow are numerical controls, not disjoint evaluation samples. Original paired-bootstrap APIs remain available in Python; this ledger does not add or display confidence intervals.


Methods and reading
Standard temperature scaling and score formulas, implemented independently in Python and browser JavaScript. No new calibration theorem or method is claimed. The ledger retains CalibrLab's [lo, hi) bins, with 1 included in the last bin, rather than silently switching endpoint conventions.
